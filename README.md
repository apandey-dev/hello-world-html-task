## 1. Project Title
**Hello World - HTML5 Starter Project**

## 2. Assignment Objective
To demonstrate the fundamental setup of a valid HTML5 document structure, including the `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, and `<body>` tags, rendering a clean "Hello World!" message in the browser.

## 3. Technologies Used
- **HTML5** (Pure semantic markup without external libraries or frameworks)

## 4. Features Implemented
- Clean and valid HTML5 boilerplate.
- Standard document metadata (`charset="UTF-8"`, mobile-friendly viewport).
- Semantic `<h1>` heading rendering exactly `Hello World!`.
- Beginner-friendly code comments explaining each section.

## 6. How to Run Locally
1. Clone or download the repository.
2. Navigate to the project directory:
   ```bash
   cd 01_Hello_World
   ```
3. Open `index.html` directly in your favorite web browser (Chrome, Firefox, Edge, Safari).

## 7. How to Open the HTML File in a Browser
- **Option A (Double Click):** Locate `index.html` in your file explorer and double-click to launch it in your default browser.
- **Option B (VS Code Live Server):** Right-click `index.html` inside VS Code and choose **Open with Live Server**.
- **Option C (Command Line):**
  - Windows: `start index.html`
  - macOS: `open index.html`
  - Linux: `xdg-open index.html`
